# ADR 0002: Встроенная горячая клавиша X11

- Статус: принято.
- Приложение может регистрировать на отдельном X11 соединении пассивную глобальную клавишу Ctrl+Space; пользователь может выключить её или выбрать другое сочетание в Settings.
- Регистрация не меняет Cinnamon/system settings, не поддерживает Wayland и не подменяет CLI или ручные действия.
- Конфликт grabs означает недоступность сочетания; пользователь выбирает другое. Переназначение сначала добавляет недостающие физические grabs, сохраняет конфигурацию, затем снимает прежние; при ошибке сохранения старые grabs остаются. Никакие чужие grabs не снимаются.
- Target фиксируется при keydown; toggle исполняется после отпускания chord и его modifiers. Удержание/repeat не создаёт новых toggle; stop/Busy не заменяют target начатой записи.
- Глобальная клавиша требует запущенного приложения. Реальная целевая GTK/X11 приёмка обязательна отдельно.
