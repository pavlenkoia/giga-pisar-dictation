# ADR 0003: Первый устанавливаемый desktop `.deb`

- Статус: принято; реализация выполнена, целевая desktop-приёмка отложена.
- Цель: первый личный desktop-выпуск для Linux Mint 22.x x86_64/Cinnamon/X11. Wayland и другие дистрибутивы/архитектуры не заявляются.
- Версия берётся только из `pyproject.toml`. Локальный `scripts/build-deb.py` собирает amd64 `.deb` через `dpkg-deb --root-owner-group`, без root, установки build-зависимостей и запуска приложения. Python-модули размещаются в `/usr/lib/giga-pisar-dictation/`; системные GI/GTK/GStreamer/X11 пакеты остаются зависимостями ОС. Launcher и desktop entry используют абсолютные системные пути.
- Пакет содержит app/status SVG icons и меню-приложение; не добавляет maintainer scripts, system service, системный autostart, пользовательский ключ/config/audio или desktop-файл в личный Desktop. Апдейт заменяет только код и ресурсы; удаление пакета не удаляет настройки.
- Обычный повторный запуск показывает окно существующего Gio-экземпляра; `--autostart` повторного экземпляра не меняет видимость. Новое autostart-окно скрывается лишь при подтверждённо зарегистрированном StatusNotifier host и подключённом AppIndicator; неизвестная готовность оставляет окно доступным. Потеря host показывает скрытое окно; восстановление не скрывает его автоматически. Поддерживаемое вторичное действие и Show window открывают окно; на AppIndicator обычный левый клик может открыть меню — принудительный click-handler не обещается.
- Выход из активного состояния требует подтверждения; подтверждённый выход отменяет локальную операцию, удаляет временное аудио и выполняет идемпотентную очистку. Серверная обработка может продолжиться после клиентской отмены.
- Autostart выключен по умолчанию и хранится как принадлежащий приложению `$XDG_CONFIG_HOME/autostart/org.gigapisar.Dictation.desktop`; отдельного bool в config.json нет. Управляются только точное ожидаемое содержимое и безопасный файл текущего пользователя; symlink, FIFO, чужое/изменённое содержимое или небезопасные права отвергаются. Каталог должен принадлежать текущему пользователю и быть каталогом, но group/other-write не является запретом; существующий режим каталога никогда не меняется. Выключить autostart перед удалением пакета.
- Данные package metadata: `Maintainer: Local package <pavlenko@it-tian.ru>` предоставлено владельцем. Copyright notice намеренно не приписывает holder; указано, что лицензия не предоставляется и пакет предназначен для personal use. Выбор/предоставление open-source license и публичная публикация не входят в решение.
- Mint/Ubuntu repository metadata подтверждены по именам зависимостей, пакет собран и проверен автономно, но в текущей задаче не устанавливался. Не объявлять готовность для повседневного использования до отдельной Mint 22.x Cinnamon/X11, tray, autostart, update/remove и LAN acceptance. Реальные microphone, server, clipboard/focus/hotkey сценарии требуют отдельного разрешения.
