# Встроенная горячая клавиша и будущая desktop-проверка

Ctrl+Space включена по умолчанию и управляется в Settings; можно выключить или выбрать другое сочетание. При конфликте приложение сообщает, что сочетание недоступно; выберите другое. Cinnamon/system settings не изменяются. CLI start/stop/cancel/status/toggle остаются доступны.

## Целевая проверка shortcut — базовая работа подтверждена пользователем

Пользователь сообщил «проверил работает» и согласовал закрытие плана с известным P2: смена keymap во время commit переназначения может оставить устаревший binding и ложный статус «active». Детали пользовательской проверки не перечислены; полный набор сценариев ниже не считается выполненным. Агент реальные grabs не регистрировал.

До проверки согласовать отдельную X11-сессию и безопасный сценарий. Проверить физический press/release: два отдельных цикла дают два toggle, удержание не повторяет действие; Busy во время финализации/запроса не начинает запись. Проверить конфликт grab без изменения системных/Cinnamon shortcut, затем Settings disable/rebind, конфликтующее переназначение (старое сочетание остаётся действующим), выход и очистку grabs. Проверить, что target сохраняется с keydown при последующем stop/Busy, а поздний ответ не активирует/не меняет фокус другого окна. Проверить восстановление статуса после изменения keymap и честное состояние при конфликте.

Эти физические действия сами по себе не разрешают включать микрофон, LAN/API, clipboard или менять фокус. Если проверка требует записи, сети или вставки, это требует отдельного согласования; вставка допускается только в специально открытое тестовое поле с отдельно согласованным тестовым clipboard. Не менять Cinnamon/system settings, автозапуск или установленные пакеты. До такого разрешения ограничиться fake-backend тестами.

## Desktop/API acceptance (не завершена)

Copy button behavior is covered by unit tests with a fake clipboard: explicit Copy overwrites empty, text, nontext (including image), or unknown clipboard contents with the complete non-empty output, without requiring a selection. Empty/no-result input performs no write. Success is reported only when readback matches; write/readback failures report inability to confirm. Copy cancels pending auto-paste restoration so it cannot later undo the user's explicit action. This policy is only for manual Copy: auto-paste retains text-only clipboard and ownership safety checks. Real GTK/X11 clipboard interaction and a paste into a dedicated test field have not been performed; unit tests do not establish desktop acceptance.

Только в целевой X11 сессии и специально открытом тестовом текстовом поле: ввести локально ключ через masked Settings entry; проверить `/health`; короткую тестовую диктовку; отмену; занятость; вставку кириллицы; изменение фокуса/закрытие тестового окна; нетекстовый clipboard; смену ownership; восстановление test clipboard; tray/window; WAV cleanup. Не использовать чужое окно или пользовательское clipboard. Ключ, аудио и текст не включать в отчёт.

Не выполнять длительную запись, нагрузочные тесты или изменения сервера. Автотесты/моки не являются GTK/X11 или реальной LAN приёмкой.

### Текущий результат

Реальная инициализация GTK и read-only X11-проверки прошли; полный сценарий записи/распознавания/вставки не выполнен. Штатный загрузчик не обнаружил сохранённый локальный ключ, выбранного WAV нет. Сеть, микрофон, clipboard и фокус при этой проверке не изменялись. Подробные результаты автоматических проверок и ревью — в `development.md`.

Для продолжения запустить приложение из checkout, открыть **Settings**, ввести новый ключ в **API key**, нажать **Save** и убедиться, что UI сообщает об успешном сохранении (не присылать ключ в чат). Приложение ищет `api-key` в `$XDG_CONFIG_HOME/giga-pisar-dictation/`, по умолчанию `~/.config/giga-pisar-dictation/`; каталог должен иметь права `0700`, файл — `0600`. Не раскрывать содержимое файла для диагностики. Затем проверить **Check server** и провести согласованный короткий сценарий исключительно в отдельном тестовом поле с тестовым clipboard.

Остаточные ограничения: HTTP не шифрует ключ/аудио; реальные серверные лимиты неизвестны; проверка XID не подтверждает конкретное поле; гонку между проверкой фокуса/клавиш и XTest нельзя полностью исключить; универсального подтверждения paste нет, задержка восстановления clipboard ограничена.

## Первый desktop `.deb` — приёмка отложена

Первый артефакт `dist/giga-pisar-dictation_0.2.0_amd64.deb` сохранён как историческое свидетельство. Текущая версия 0.2.1 добавляет безопасный fallback Settings при недоступном autostart; сборка и проверки записаны в `development.md`. Реальную приёмку выполнять только отдельным разрешённым сценарием в чистой Linux Mint 22.x x86_64/Cinnamon/X11-среде; текущий worker не устанавливал пакет и не запускал desktop launcher.

В разрешённом Mint GUI-пакетном сценарии проверить: установить `.deb` с зависимостями; запустить из меню и созданного пользователем ярлыка; первый запуск показывает Settings при отсутствующем ключе; обычный повторный запуск показывает окно существующего экземпляра; доступность меню tray и Show window; крестик скрывает окно только при подтверждённом host, при потере host окно восстанавливается, при неизвестном/отсутствующем tray оно остаётся доступным. На AppIndicator обычный левый клик может открывать меню; Show window через меню и запуск ярлыком остаются поддержанными путями.

Проверить login autostart выключенным по умолчанию; включение/выключение только через Settings → Save; при autostart нет записи, при доступном tray окно скрыто, при недоступном/неизвестном tray окно видно. Потеря tray во время скрытого запуска показывает окно; появление host не скрывает его снова. Выключить autostart перед удалением пакета. Проверить обновление прежнего пакета с сохранением ключа/config и удаление пакета без удаления user settings. File permissions/чужой файл/symlink сценарии остаются fake/temporary-XDG тестами, не изменять настоящие настройки другого приложения.

Выход во время RECORDING/FINALIZING/REQUESTING и подтверждение операции с настоящими микрофоном/LAN, а также любые clipboard/focus/hotkey действия выполнять только по отдельно утверждённому безопасному сценарию. Не считать локальную сборку, fake tests или `--help` приёмкой GTK, tray, autostart login, microphone, LAN или insertion.

Фактические package checks, dependency metadata и lintian warnings записываются в [`development.md`](development.md). Текущая target Mint desktop acceptance не выполнена.
