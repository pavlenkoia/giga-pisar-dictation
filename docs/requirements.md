# Принятые требования прототипа

- Linux X11/Cinnamon, Python 3 + системные GI bindings (GTK 3, Gio, Soup 3, GStreamer). Только русский ASR; клиент не загружает локальную модель.
- Ручные `start`, `stop`, `cancel`, `status`, `toggle`; занятая запись во время запроса блокируется. Неизвестная команда и команда без работающего экземпляра не запускают скрытую запись.
- API key читается только из отдельного приватного файла, не из argv и не из журнала. URL без userinfo/query/fragment. HTTP допустим только в доверенной LAN; Authorization только в заголовке, redirects запрещены.
- WAV mono S16LE 16kHz, временное приватное хранение, удаление после запроса/отмены/ошибки; лимит 5 минут отбрасывает запись. Запросы отменяемы; поздний ответ отменённого поколения игнорируется.
- Автовставка только при совпадении исходного X11 окна, существующем окне, текстовом clipboard и отсутствии удерживаемых модификаторов. Фокус не восстанавливается. При риске вставка отказывается, текст остаётся в окне.
- Ручная кнопка Copy по явному решению пользователя заменяет любое содержимое clipboard (включая изображение/неизвестные данные) полным непустым результатом независимо от выделения. Пустой/отсутствующий результат не меняет clipboard; интерфейс подтверждает успех только при совпадении readback. Эта политика не ослабляет проверки автовставки.
- Встроенный X11 shortcut включён по умолчанию (Ctrl+Space), настраивается или выключается в Settings; конфликты показываются как недоступность shortcut, Cinnamon не меняется. Wayland не поддерживается.
- Нет истории аудио/текста и журналирования ключа, аудио, ответа или транскрипта.
- Автономные тесты не трогают физический микрофон, реальный clipboard, focus/hotkeys, LAN сервер либо пользовательские настройки.

## Согласованные требования первого устанавливаемого выпуска

Статус: согласовано и реализовано в исходниках; `.deb` 0.2.0 собран и автономно проверен, но не установлен. Приёмка в целевой Mint/Cinnamon/X11-сессии, реальный tray host и LAN-сценарий ещё не выполнены.

- Целевая платформа: Linux Mint 22.x, x86_64, Cinnamon/X11. Совместимость с другими дистрибутивами и рабочими столами не обещается без проверки; Wayland остаётся вне объёма.
- Формат установки: `.deb`, системные зависимости, иконка и пункт в меню приложений; возможность добавить ярлык на рабочий стол. Исходники и ручная настройка Python для запуска не требуются.
- Крестик скрывает окно в трей, не завершает приложение. Если трей недоступен, последнее окно не скрывается.
- Открытие окна доступно через Show window в меню и повторный запуск ярлыка; поддерживаемое хостом secondary activation также открывает окно. Обычный левый клик AppIndicator может открыть меню и не обещается как прямой click-handler. Значок отображает ожидание, запись, распознавание и ошибку; меню содержит явный пункт «Выйти».
- Повторный запуск через ярлык открывает окно существующего экземпляра, не создаёт второй экземпляр.
- Автозапуск при входе выключен по умолчанию и включается пользователем в Settings. Если безопасная проверка autostart недоступна, Settings всё равно открывается, переключатель недоступен и сохранение остальных настроек не читает/не меняет autostart. При автозапуске приложение не начинает запись; скрытый старт допустим только при подтверждённо подключённом tray host, а неизвестный/недоступный host оставляет окно видимым. Потеря host восстанавливает скрытое окно, восстановление host не скрывает окно автоматически.
- При выходе во время записи или отправки требуется подтверждение. Подтверждённый выход отменяет операцию и удаляет временное аудио; это не гарантирует отмену уже начавшейся серверной обработки.
- При отсутствии настроенного API-ключа первый запуск открывает существующий Settings для адреса сервера и API-ключа. После сохранения проверка соединения доступна кнопкой Check server в главном окне. Ключ и пользовательские настройки не включаются в пакет.
- Обновление новым `.deb` сохраняет настройки и ключ.
- Русификацию и визуальную доработку интерфейса можно выполнить после первой упаковки и доставить последующим обновлением.

Полная приёмка требует отдельного разрешённого испытания в целевой X11-сессии и с LAN API. Код/автотесты этого не заменяют; данный шаг не выполняет такое испытание.
