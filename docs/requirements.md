# Принятые требования прототипа

- Linux X11/Cinnamon, Python 3 + системные GI bindings (GTK 3, Gio, Soup 3, GStreamer). Только русский ASR; клиент не загружает локальную модель.
- Ручные `start`, `stop`, `cancel`, `status`, `toggle`; занятая запись во время запроса блокируется. Неизвестная команда и команда без работающего экземпляра не запускают скрытую запись.
- API key читается только из отдельного приватного файла, не из argv и не из журнала. URL без userinfo/query/fragment. HTTP допустим только в доверенной LAN; Authorization только в заголовке, redirects запрещены.
- WAV mono S16LE 16kHz, временное приватное хранение, удаление после запроса/отмены/ошибки; лимит 5 минут отбрасывает запись. Запросы отменяемы; поздний ответ отменённого поколения игнорируется.
- Автовставка устанавливает распознанный непустой текст независимо от прежнего содержимого clipboard; прежнее содержимое не читается/не сохраняется и никогда не восстанавливается. Перед XTest подтверждаются readback нового текста, ожидаемый X11 owner/generation, исходное существующее активное окно и отсутствие удерживаемых модификаторов; ожидание асинхронно ограничено 200 мс. При отказе новый текст остаётся в clipboard, если его не заменил пользователь/другой владелец. Фокус не восстанавливается; успех означает отправку команды, не гарантированную доставку.
- Кнопка «Копировать» по явному решению пользователя заменяет любое содержимое clipboard (включая изображение/неизвестные данные) полным непустым результатом независимо от выделения. Пустой/отсутствующий результат не меняет clipboard; интерфейс подтверждает успех только при совпадении readback. Эта политика не ослабляет проверки автовставки.
- Встроенный X11 shortcut включён по умолчанию (Ctrl+Space), настраивается или выключается в «Настройках»; конфликты показываются как недоступность shortcut, Cinnamon не меняется. Wayland не поддерживается.
- Настройки выбора аудио показывают список «Микрофон»: системный источник по умолчанию и доступные источники с понятными именами. Список читается через GStreamer DeviceMonitor без запуска capture; выбранный GStreamer `device` ID сохраняется в прежнем `config.audio_source` (пустое значение — системный по умолчанию). Недоступный сохранённый источник остаётся выбранным до явного выбора; сбой перечисления не теряет настройку. Перечень обновляется при открытии настроек; live hotplug не обещан.
- Нет истории аудио/текста и журналирования ключа, аудио, ответа или транскрипта.
- Автономные тесты не трогают физический микрофон, реальный clipboard, focus/hotkeys, LAN сервер либо пользовательские настройки.

## Согласованные требования первого устанавливаемого выпуска

Статус базового выпуска: `.deb` 0.2.0 собран и автономно проверен, но не установлен. Выпуск 0.2.2 русифицировал интерфейс и CLI; выпуск 0.2.3 содержит исправление первой автовставки и согласованную политику замены прежнего clipboard. Пользователь подтвердил базовую работу после изменения политики; это не подтверждает все race-сценарии или полную desktop-приёмку. Актуальные автономные проверки выпуска описаны в `development.md`. Приёмка в целевой Mint/Cinnamon/X11-сессии, tray host и LAN-сценарий не выполнены.

- Linux desktop и CLI полностью русскоязычны; отображаемое имя — «Гига Писарь». Технические команды IPC, протокол и имена файлов совместимы.

- Целевая платформа: Linux Mint 22.x, x86_64, Cinnamon/X11. Совместимость с другими дистрибутивами и рабочими столами не обещается без проверки; Wayland остаётся вне объёма.
- Формат установки: `.deb`, системные зависимости, иконка и пункт в меню приложений; возможность добавить ярлык на рабочий стол. Исходники и ручная настройка Python для запуска не требуются.
- Крестик скрывает окно в трей, не завершает приложение. Если трей недоступен, последнее окно не скрывается.
- Открытие окна доступно через «Показать окно» в меню и повторный запуск ярлыка; поддерживаемое хостом secondary activation также открывает окно. Обычный левый клик AppIndicator может открыть меню и не обещается как прямой click-handler. Значок отображает ожидание, запись, распознавание и ошибку; меню содержит «Показать окно», разделитель, «Начать», «Остановить», «Отменить», «Переключить запись», разделитель и «Выйти». Команда `status` остаётся доступна через CLI/IPC.
- Повторный запуск через ярлык открывает окно существующего экземпляра, не создаёт второй экземпляр.
- Автозапуск при входе выключен по умолчанию и включается пользователем в «Настройках». Если безопасная проверка autostart недоступна, «Настройки» всё равно открываются, переключатель недоступен и сохранение остальных настроек не читает/не меняет autostart. При автозапуске приложение не начинает запись; скрытый старт допустим только при подтверждённо подключённом tray host, а неизвестный/недоступный host оставляет окно видимым. Потеря host восстанавливает скрытое окно, восстановление host не скрывает окно автоматически.
- При выходе во время записи или отправки требуется подтверждение. Подтверждённый выход отменяет операцию и удаляет временное аудио; это не гарантирует отмену уже начавшейся серверной обработки.
- Отказ автоматической вставки показывает безопасную русскую причину, если её достоверно определяют текущие проверки (например, выключенная функция, недоступное исходное окно/X11, отсутствие подтверждения установленного текста, удерживаемые клавиши или отказ XTest). Для подтверждения clipboard используется неблокирующее ожидание до 200 мс; уведомление само по себе не доказывает владение: проверяются поколение, X11 owner и readback нового текста. Неожиданные ошибки показываются общей фразой без деталей исключения. Успешная отправка клавиш обозначается только как команда отправлена, доставка не подтверждена.
- При отсутствии настроенного API-ключа первый запуск открывает существующие «Настройки» для адреса сервера и API-ключа. После сохранения проверка соединения доступна кнопкой «Проверить сервер» в главном окне. Ключ и пользовательские настройки не включаются в пакет.
- Если безопасная проверка автозапуска обнаруживает небезопасные права каталога, переключатель выключен, приложение объясняет, что каталог имеет небезопасные права, а остальные настройки сохраняются без чтения или изменения autostart. Исправление прав выполняется пользователем отдельно; приложение не меняет их автоматически.
- Обновление новым `.deb` сохраняет настройки и ключ.
- Автозапуск распознаёт ровно прежний и новый UTF-8 desktop-шаблоны. Чтение не мигрирует прежний файл; при явном включении новый файл записывается по-русски, выключение удаляет распознанный старый или новый файл. Чужие файлы остаются защищены.
- Русификацию и визуальную доработку интерфейса можно выполнить после первой упаковки и доставить последующим обновлением.

Полная приёмка требует отдельного разрешённого испытания в целевой X11-сессии и с LAN API. Код/автотесты этого не заменяют; данный шаг не выполняет такое испытание.
