# Документация Giga Pisar Dictation

## Документы и статус

- [Исходная спецификация](initial-spec.md) — предварительный черновик и отправная точка проектирования. Описывает первоначальный объём, предложения и открытые вопросы; не фиксирует окончательный стек или архитектуру.

Актуальные требования, архитектуру и инструкции по запуску добавим по мере согласования и реализации. Значимые архитектурные решения будем хранить в `decisions/`.

Исходный черновик сохраняем как историческую отправную точку; принятые изменения и уточнения оформляем в актуальных документах, не переписывая его задним числом.

## Где искать процесс и планы

- [Правила работы агентов](../AGENTS.md) — рабочий процесс, проверки и ограничения.
- Планы отдельных задач — в `../plans/` (каталог появится с первым планом). План описывает конкретную реализацию, а не заменяет требования к продукту.
