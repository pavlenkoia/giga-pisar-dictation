# Документация «Гига Писарь»

## Текущий статус

Опубликован [выпуск 0.2.3](https://github.com/pavlenkoia/giga-pisar-dictation/releases/tag/v0.2.3): пакет `.deb` для amd64 и файл контрольных сумм `SHA256SUMS`. Сборка через GitHub Actions, 133 теста и проверки пакета прошли; скачанные файлы отдельно проверены. Настройка автоматического выпуска влита в `main`.

Целевая платформа — Linux Mint 22.x, Cinnamon/X11, x86_64. Пользователь подтвердил базовую работу горячей клавиши и первой вставки. Полная проверка в целевой графической сессии и все пограничные сценарии ещё не завершены; автотесты её не заменяют.

Инструкция по скачиванию, установке и первому запуску находится в [основном README](../README.md).

## Документы и решения

- [Исходная спецификация](initial-spec.md) — исторический черновик; рекомендации в нём не подменяют принятые решения.
- [Принятые требования](requirements.md) — границы проекта, безопасность и реализованное поведение приложения.
- [ADR 0001](decisions/0001-desktop-prototype.md) — выбор стека и архитектуры; прежнее решение о горячей клавише заменено ADR 0002.
- [ADR 0002](decisions/0002-built-in-x11-shortcut.md) — встроенная глобальная горячая клавиша X11.
- [ADR 0003](decisions/0003-desktop-deb-release.md) — установка через `.deb`, поведение окна и трея, пользовательский автозапуск.
- [ADR 0004](decisions/0004-github-deb-releases.md) — публикация пакетов в GitHub Releases без предоставления лицензии.
- [ADR 0005](decisions/0005-clipboard-restoration.md) — best-effort восстановление текста/изображения clipboard после автоматической вставки.
- [Контракт API](api-contract.md) — отправка аудиофайла, проверка доступности сервера и обработка ошибок.
- [Разработка](development.md) — команды проверок, фактические результаты сборки и известные ограничения.
- [Выпуски](releases.md) — автоматическая публикация, проверка контрольной суммы и ручная установка.
- [Ручная настройка и тестирование](manual-testing.md) — горячая клавиша и сценарии проверки в графической сессии.

Базовая работа горячей клавиши подтверждена пользователем. Её план закрыт с согласованным ограничением уровня P2: изменение раскладки клавиш во время сохранения нового сочетания может оставить устаревшую привязку и неверный статус доступности. Подробности — в [документе о разработке](development.md).

Исходный черновик и исторические результаты сохраняем. Новые требования и уточнения оформляем в актуальных документах и решениях, не переписывая историю задним числом.
