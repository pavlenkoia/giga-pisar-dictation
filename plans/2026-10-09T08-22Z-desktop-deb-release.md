# Первый устанавливаемый desktop-выпуск

## Контекст и цель

Превратить GTK/X11-прототип в устанавливаемое приложение для Linux Mint 22.x x86_64/Cinnamon: `.deb`, меню/ярлык, управляемый трей, первый запуск, необязательный автозапуск, сохранение настроек при обновлении. Требования согласованы в `docs/requirements.md`. Русификация и визуальная переработка — последующий этап.

## Предварительные находки

- `pyproject.toml`: setuptools, entry point, версия 0.1.0; GI-зависимости системные.
- `gui.py`: уже есть Ayatana/AppIndicator, меню и скрытие окна. Создание indicator пока не доказывает наличие tray host; без indicator крестик завершает приложение. Значок не показывает состояние.
- `app.py`: Gio single-instance IPC уже есть, но повторный запуск без аргументов сейчас трактуется как toggle, а не открытие окна. Это нужно исправить без изменения семантики явных команд.
- `__main__.py`: создаёт окно и контроллер; нет отдельного режима автозапуска.
- `config.py`: XDG config, отдельный ключ, атомарные записи 0600 и каталог приложения 0700. Сохранить формат и совместимость старых настроек.
- `desktop.py`: существующие `shutdown`, `save_settings`, `health` и `command`; контроллер уже различает RECORDING/FINALIZING/REQUESTING и отменяет операции. Shutdown вызывается и при Quit, и в finally — повторный вызов должен быть безопасен.
- `audio.py`: требуются pulsesrc, audioconvert, audioresample, wavenc, filesink; X11 использует libX11 и libXtst.
- `tests/test_ipc_dbus.py`, `tests/ipc_scenario.py`: готовая изолированная D-Bus проверка без запуска реального рабочего стола.
- На текущем хосте доступны dpkg-deb, dpkg-buildpackage, lintian, desktop-file-validate; dh не найден. Выбран локальный builder через dpkg-deb, без установки build-зависимостей.

## Подход

### Упаковка

- Локальная сборка `scripts/build-deb.py` через `dpkg-deb --root-owner-group`, без root, скачивания зависимостей и исполнения приложения. Результат: `dist/giga-pisar-dictation_0.2.0_amd64.deb`. Версия берётся из `pyproject.toml`, без второго независимого источника.
- Python-код установить в `/usr/lib/giga-pisar-dictation/`, launcher в `/usr/bin/giga-pisar-dictation` с `/usr/bin/python3` и явным путём к установленным модулям. Работает вне checkout и без PYTHONPATH. GTK/GI не включать в архив.
- `packaging/deb/control.in`: зависимости Python >=3.10, python3-gi, python3-gi-cairo, gir1.2-gtk-3.0, gir1.2-soup-3.0, gir1.2-gstreamer-1.0, gir1.2-ayatanaappindicator3-0.1, gstreamer1.0-plugins-base/good/pulseaudio, libx11-6, libxtst6. Сверить реальные имена пакетов для Mint 22/Ubuntu 24.04 через доступные metadata, не устанавливая их; блокер сообщить, не заменить зависимость молча.
- Desktop entry с APP_ID `org.gigapisar.Dictation`, `Terminal=false`, абсолютным Exec, иконкой и подходящими категориями; SVG-иконки в hicolor для приложения и состояний. Ярлык пользователь добавляет средствами Mint: установщик не пишет на личный рабочий стол.
- Не добавлять postinst/prerm, service, системный автозапуск, конфигурацию сервера, ключи и пользовательские данные. Обновление заменяет только программные файлы, удаление пакета не удаляет личные настройки. Пакет предназначен для личного использования; публичная публикация и выбор лицензии вне задачи.

### Запуск и lifecycle

- Обычный запуск без аргументов открывает/поднимает окно, в том числе у существующего экземпляра. Никогда не вызывает toggle. Явные start/stop/cancel/status/toggle сохраняют контракт и отказ без работающего экземпляра.
- Новый флаг `--autostart`: у нового экземпляра скрытое окно только при готовой конфигурации и подтверждённом доступном трее; иначе видимое окно. Повторный autostart не открывает окно и не меняет запись существующего экземпляра.
- Убрать ранний show_all из конструктора: решение о показе после подключения effects/controller. При отсутствии ключа открыть окно и существующие Settings через GLib idle; не запускать микрофон. Не путать отсутствие ключа с ошибкой чтения приватного файла: ошибку показать безопасно. Настройка URL/ключа и кнопка Check server переиспользуются; проверка не требует записи.
- X11 — явная граница поддержки: при Wayland/отсутствии X11 сообщить ограничение, не регистрировать shortcut и не обещать вставку. Пакет не устанавливает X-сервер и не переключает сессию.
- Все пути явного выхода ведут в одну функцию: в RECORDING/FINALIZING/REQUESTING подтверждение, при отказе работа продолжается, при согласии существующая отмена/shutdown и удаление WAV. Защитить повторный shutdown и поздние callbacks; результат/аудио не сохранять. Серверная отмена не гарантируется.

### Трей

- Переиспользовать Ayatana/AppIndicator и меню. Выделить тестируемый adapter/policy для доступности и состояния, а не считать наличие объекта Indicator доказательством работающего трея.
- Проверять host/connection через доступные API indicator и session D-Bus StatusNotifierWatcher. Только подтверждённая готовность разрешает скрытие; неизвестное состояние означает видимое окно. При потере host скрытое окно показать, при восстановлении не скрывать автоматически. Подписки освобождать при shutdown.
- Крестик при готовом трее скрывает окно; без трея оставляет доступное окно с пояснением, не завершает приложение. Меню: Show window и Quit плюс существующие команды.
- Привязать поддерживаемое хостом действие открытия к Show window (включая secondary activation там, где доступна). В AppIndicator обычный левый клик может открывать меню: это ограничение платформы явно описать, не обещать принудительный click-handler. Открытие окна всегда доступно через меню и ярлык.
- Значки/tooltip отражают Controller.State: IDLE/RESULT — ожидание, RECORDING — запись, FINALIZING/REQUESTING — обработка, ERROR — ошибка. Обновлять на всех переходах, включая limit/error/late callback. Не помещать транскрипт или ключ в tooltip.

### Пользовательский автозапуск

- Новый `autostart.py`: собственный файл `$XDG_CONFIG_HOME/autostart/org.gigapisar.Dictation.desktop` с Exec `/usr/bin/giga-pisar-dictation --autostart`. Отсутствие файла означает выключено; состояние checkbox читается из файла, без дублирующего bool в config.json.
- Settings содержит переключатель. Чтение диалога ничего не создаёт; запись только по Save, атомарно. Управлять только принадлежащим приложению файлом; отвергать symlink, небезопасные/чужие файлы и не перезаписывать их. Не применять правило 0700 каталога приложения к общему XDG autostart-каталогу и не менять его права.
- При ошибке сохранения не показывать успех/включение; согласованно восстановить предыдущее собственное состояние autostart при последующей ошибке сохранения остальных настроек. Сохранить нынешние проверки ключа, URL и shortcut. На удаление собственного autostart отдельное явное действие выключения; документировать выключение перед удалением пакета.

## Границы

Не входят русификация, redesign, Wayland, другие архитектуры/дистрибутивы, автообновление, изменение ASR/API/clipboard-политики и известный согласованный P2 shortcut. Точечные изменения lifecycle не должны превращаться в рефакторинг приложения.

## Переиспользование

- `app.py:CommandApplication` и APP_ID — один экземпляр и session-bus IPC.
- `gui.py:DesktopWindow.settings_dialog`, `_create_indicator`, `refresh` — существующее окно/меню, без нового мастера.

- `config.py:load_config/load_api_key/save_config/save_api_key` — совместимость и приватное хранение; общий autostart-каталог требует отдельного адаптера.

## Проверки и критерии готовности

### Автономные (в рамках задачи)

- `PYTHONPATH=src /usr/bin/python3 -m unittest discover -s tests -v`
- `/usr/bin/python3 -m compileall -q src tests scripts`
- `PYTHONPATH=src /usr/bin/python3 -m giga_pisar_dictation --help`
- `git diff --check`
- `/usr/bin/python3 scripts/build-deb.py`; `dpkg-deb --info dist/giga-pisar-dictation_0.2.0_amd64.deb`; `dpkg-deb --contents dist/giga-pisar-dictation_0.2.0_amd64.deb`
- `desktop-file-validate packaging/org.gigapisar.Dictation.desktop`; `lintian dist/giga-pisar-dictation_0.2.0_amd64.deb` — исправить ошибки, разобрать и документировать оставшиеся warnings, не скрывать их.
- Распаковать пакет в temporary directory: проверить owner/mode, Depends, launcher и import/help вне checkout без PYTHONPATH, наличие иконок/desktop entry; отсутствие ключей, config, аудио, pycache, тестов и maintainer scripts. Не запускать desktop launcher без --help.
- IPC под `dbus-run-session` с fake owner: обычный повторный запуск → show, явный toggle → toggle, повторный autostart → no-op; без owner команды не создают GUI/запись.
- Fake tray/view tests: подтверждённый/неизвестный/отсутствующий host, его потеря, повторное появление, show из меню; каждый State; отсутствие утечки данных; крестик; подтверждение/отказ выхода в recording/finalizing/requesting; двойной shutdown и поздний callback.
- Временные XDG-каталоги: autostart по умолчанию выключен, включение/выключение/повторное сохранение, чужой файл/symlink, ошибка/rollback, сохранение прежних config/key. Новые тесты не читают и не меняют настоящие настройки, clipboard, focus/hotkeys, не записывают микрофон и не обращаются к LAN.
- Готовность реализации: проверки реально выполнены, `.deb` собран, замечания reviewer обработаны, документация отражает фактические результаты. Пропуски проверок явно указаны.

### Отложенная приёмка (только отдельное разрешение)

На чистом Mint 22.x x86_64/Cinnamon/X11: установка через GUI с зависимостями; запуск из меню и пользовательского ярлыка; первый запуск Settings; tray и потеря host; повторный запуск без toggle; включение/выключение автозапуска и повторный вход; отказ/подтверждение выхода во время операций; обновление предыдущего пакета с сохранением ключа/settings; удаление без потери личных настроек. Отдельно согласовать реальные микрофон/LAN/clipboard/hotkeys сценарии диктовки. Не заявлять готовность к повседневному использованию по одной сборке или mock-тестам.
