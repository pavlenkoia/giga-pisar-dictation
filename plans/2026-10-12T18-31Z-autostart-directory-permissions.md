# Исправление блокировки автозапуска по правам каталога

## Цель
Автозапуск работает с пользовательским каталогом ~/.config/autostart с правами 0775 без chmod и без ошибочно отключённой галки.

## Границы и пути
- src/giga_pisar_dictation/autostart.py: убрать отказ по group/other-write у каталога, не менять его права.
- src/giga_pisar_dictation/gui.py: удалить диагностику этого отказа; сохранить обработку реальных ошибок доступа.
- tests/test_autostart.py: заменить тест отказа регрессиями успешного включения/выключения и доступного переключателя с каталогом 0775; проверить сохранение режима каталога и реальный отказ записи через mock.
- docs/requirements.md, docs/decisions/0003-desktop-deb-release.md: явно заменить прежнее требование блокировки каталога.
- docs/development.md: записать фактические проверки и ограничения.

Не менять установку, системные настройки, пользовательский autostart, clipboard, микрофон, LAN; не выполнять commit/push/release. Не расширять задачу на остальные механизмы безопасности.

## Решения для согласования
Прежнее требование отказа при group/other-writable каталоге отменяется по запросу пользователя. Приложение не требует chmod; фактические ошибки файловой операции не выдаются за успех. Проверки принадлежащего приложению файла не расширяются и не добавляются новые ограничения.

## Шаги
1. Получить явное одобрение плана в чате: Plannotator недоступен. Отдельно подтвердить запуск предусмотренных проектом worker и reviewer с моделями из .pi/settings.json, учитывая обещание не запускать платных агентов без согласия.
2. Встроенный worker со свежим контекстом выполняет только перечисленные изменения.
3. Основной агент независимо проверяет diff и запускает проверки.
4. Свежий read-only reviewer проверяет план, требования, diff; подтверждённые замечания возвращаются worker.

## Критерии готовности и проверки
- Каталог 0775: чтение состояния, включение, повторное включение, выключение работают; права каталога неизменны; чужие записи каталога не затронуты.
- Fake GTK settings с настоящим AutostartFile во временном XDG-каталоге 0775: переключатель доступен, сохранение передаёт выбранное состояние.
- Реальный отказ записи через mock не даёт ложного успешного сохранения; регрессии защиты файлов остаются зелёными.
- PYTHONPATH=src /usr/bin/python3 -m unittest discover -s tests -v
- /usr/bin/python3 -m compileall -q src tests scripts
- git diff --check
- Документы отражают новую политику, исторические отчёты не переписываются.

GTK/X11 и login autostart на удалённом компьютере не проверяются без отдельного разрешённого сценария. Изменение исходников не равно обновлению установленного пакета: сборка/публикация/установка согласуются отдельно.
