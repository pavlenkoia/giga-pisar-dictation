# Русификация приложения: «Гига Писарь»

## Контекст
Пользователь запросил русификацию приложения. Сейчас окно GTK, кнопки, настройки, меню трея и сообщения в `src/giga_pisar_dictation/gui.py` преимущественно английские. По замечанию пользователя план перенесён в ветку задачи `feature/russian-interface`: ветка создана и выбрана, файл плана сохранён в рабочем дереве этой ветки. Изменений кода нет; план пока не закоммичен. Реализация будет выполняться в этой же ветке.

## Подход
Перевести строки непосредственно в существующих модулях, без gettext и переключателя языка. Сохранить протоколы и внутренние команды. Перед переводом кнопок отделить подписи от идентификаторов действий: сейчас `_button` использует английскую подпись как команду. Заголовки окна/трея, описания пакета и desktop-ярлыка получают название «Гига Писарь». Для отображения состояний трея использовать русские подписи, не `state.name.lower()`.
Все подписи и стандартные кнопки GTK, а также разделы справки argparse должны быть русскими независимо от системного LANG; не менять глобальную locale процесса. Технические обозначения API, HTTP, X11, JSON и Ctrl+Space сохраняются.
Согласовано пользователем: русский — единственный язык; переводится весь пользовательский текст, включая CLI и ошибки; отображаемое название — «Гига Писарь». Переключатель и инфраструктура нескольких языков не нужны.
Обнаружены дополнительные источники: `Controller.message`, `DesktopEffects` (статусы, предупреждения, ошибки), `CommandApplication` (CLI). Машинные команды и JSON-статусы нужно сохранить.

## Затрагиваемые файлы
- `src/giga_pisar_dictation/{gui,desktop,controller}.py` — все подписи, диалоги, состояния и предупреждения.
- `src/giga_pisar_dictation/{__main__,app,api,config,audio,hotkey,x11,autostart}.py` — CLI, ошибки, автозапуск.
- `packaging/org.gigapisar.Dictation.desktop`, `packaging/deb/control.in`, `pyproject.toml` — отображаемое имя и описания; версия 0.2.2 для отдельного обновления.
- `scripts/build-deb.py` — русская справка и собственные ошибки сборщика; актуальная запись изменений без утверждения «Initial» для нового выпуска.
- `tests/test_{api_ipc_audio,app_routing,config_controller,desktop_hotkey,desktop_safety,hotkey,audio_lifecycle,autostart,tray_lifecycle,packaging,ipc_dbus}.py`, `tests/ipc_scenario.py` — затронутые ожидания и регрессии; при необходимости новый `tests/test_russian_ui.py`.
- `README.md`, `docs/{README,requirements,manual-testing,development}.md` — новое имя, текущие подписи, требования, результаты и сценарии приёмки. Исходную спецификацию и исторические ADR не переписывать.

## Повторное использование
- `DesktopWindow._action` и `_menu_action` — существующие идентификаторы действий.
- `Controller` в `controller.py`, `DesktopEffects` в `desktop.py`, `ApiClient` в `api.py`: сохранить обработку состояний, ограничений и безопасных ошибок.
- `AutostartFile._read_owned/is_enabled/set_enabled` в `autostart.py`: сейчас файл распознаётся по точному совпадению байтов. Добавить новый UTF-8 шаблон и признание строго двух точных шаблонов (старый и новый), ограничивая чтение максимальной их длиной. Не расширять доверие к произвольным desktop-файлам.
- Fake GTK/Indicator из `tests/test_tray_lifecycle.py`, fake settings из `tests/test_autostart.py`, локальный HTTP сервер и временная D-Bus-сессия из существующих тестов; сборка/распаковка и relocated launcher из `tests/test_packaging.py`.

## Согласованные решения
- Только русский интерфейс, все пользовательские тексты и справка CLI на русском.
- Отображаемое название «Гига Писарь»; технические имена пакета, команды запуска, конфигурации и APP_ID сохранить ради совместимости обновления.
- Не переводить транскрипты, введённые пользователем значения и машинные идентификаторы (`start/stop/cancel/status/toggle`, JSON-поля и значения статусов, enum, desktop/иконки/APP_ID).
- Старый автозапуск после обновления должен оставаться распознанным и управляемым. Не мигрировать его автоматически при запуске/чтении: старое имя в уже существующем пользовательском файле допустимо до явного выключения/включения автозапуска; новые записи — «Гига Писарь». Реальные пользовательские файлы в этой задаче не менять.
- Ошибки API сейчас классифицируются по английскому тексту исключений. При переводе выходных сообщений не привязывать классификацию к переводу: для Gio использовать домен/код CANCELLED и TIMED_OUT, сохранив fallback для обычных исключений. Проверить русские/английские сообщения при одинаковых кодах (устранить известную зависимость теста отмены от locale).
- Без нового поведения диктовки, исправления известной гонки hotkey MappingNotify, переименования Python-модулей или миграции конфигурации. Системные инструменты/библиотеки могут выдавать собственные сообщения; переводим собственную пользовательскую поверхность приложения, не выводим сырой ответ сервера.

## Проверки
Автономные команды после реализации (в фазе планирования не запускать):
```sh
PYTHONPATH=src /usr/bin/python3 -m unittest discover -s tests -v
/usr/bin/python3 -m compileall -q src tests scripts
LANG=C PYTHONPATH=src /usr/bin/python3 -m giga_pisar_dictation --help
/usr/bin/python3 scripts/build-deb.py --help
/usr/bin/python3 scripts/build-deb.py
desktop-file-validate packaging/org.gigapisar.Dictation.desktop
git diff --check
```
Проверить `dpkg-deb --info/--contents` нового пакета, распаковку в временную директорию и `--help` relocated launcher без PYTHONPATH и вне checkout; lintian при доступности (два известных предупреждения не маскировать). Не устанавливать пакет и зависимости.

Критерии готовности:
- Все собственные пользовательские подписи/сообщения/справка русские, отображаемое имя — «Гига Писарь»; технические токены и данные не изменены.
- Все кнопки и пункты меню вызывают прежние действия; JSON IPC, конфигурация, ключ и политики безопасности совместимы.
- Старый и новый точные шаблоны автозапуска поддержаны; чтение не переписывает файл, чужие/небезопасные файлы отвергаются.
- Автотесты и проверки пакета проходят; документация отражает изменение и фактические результаты.

Отдельная целевая GTK/X11-приёмка после разрешения: окно, меню трея, настройки, диалоги и длинные русские подписи не обрезаются/не перекрываются. При необходимости локально адаптировать компоновку кнопок/размер окна, без редизайна. Запись, LAN, clipboard, фокус, горячие клавиши, установка и login autostart — только по отдельно согласованному сценарию. Без разрешения эти сценарии явно отметить непроверенными: моки и сборка не заменяют графическую приёмку.
